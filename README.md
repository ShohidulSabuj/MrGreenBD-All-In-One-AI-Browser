Here is the complete list of features included in MrGreenBD All in One AI+ Browser (v4.0):
 * Cross-Platform Adaptive Interface: Responsive Jetpack Compose UI designed for Android smartphones, tablets, and Android TV (Leanback launcher support).
 * Android TV Remote Cursor & Media Controls: Virtual D-pad cursor navigation for non-touch TV screens along with remote play/pause shortcuts.
 * AI+ Assistant Hub & Sidebar: Built-in AI panel powered by Gemini 2.0 Flash (with an offline local preview fallback) to summarize webpages, translate and explain content in Bengali, ask custom questions, and copy responses.
 * Ad, Tracker & Pop-Up Shield: Blocks known ad networks, analytics trackers, pop-ups, and suspicious redirects with a live blocked-ad counter.
 * Built-In Media Stream Detector & ExoPlayer: Automatically detects streamable video links (.mp4, .m3u8, .webm) on webpages with a floating player, Picture-in-Picture (PiP) mode, and one-tap download.
 * Multi-Tab & Private Browsing: Supports standard and private tabs, Speed Dial home screen with pinned bookmarks, and quick session restore.
 * Reader Mode & Force Dark Web: Distraction-free reading layout for articles and automatic dark theme injection for bright websites.
 * Custom Search Engines & DNS Profiles: Switch between Google, DuckDuckGo, Brave Search, and Bing, alongside Cloudflare, NextDNS, AdGuard, or system DNS profiles.
 * Local Library & JSON Backup: Offline Room database for bookmarks and browsing history with JSON clipboard export/import support.
 * Security & Customization Tools: Biometric and PIN app lock, one-handed bottom address bar toggle, desktop user-agent switch, smart download manager integration, and custom JavaScript UserScript execution.
