# MrGreenBD All in One AI+ Browser v4.0 - APK Build Guide

## পিসি ছাড়াই GitHub থেকে সরাসরি APK তৈরির নিয়ম:
1. GitHub-এ লগইন করে একটি নতুন Repository তৈরি করুন (যেমন: `MrGreenBD-All-In-One-AI-Browser`)।
2. এই ZIP ফাইলটি আনজিপ করে ভেতরের সব ফাইল ও ফোল্ডার (`.github`, `app`, `build.gradle.kts`, `settings.gradle.kts`) আপনার GitHub Repository-তে আপলোড করুন।
3. আপলোড হয়ে গেলে উপরের **Actions** ট্যাবে যান এবং **Build MrGreenBD All in One AI+ Browser APK** ওয়ার্কফ্লোটি চালান।
4. প্রায় ২-৩ মিনিট পর বিল্ড সম্পন্ন হলে নিচে **Artifacts** সেকশনে `MrGreenBD-All-In-One-AI-Browser-v4-APK` দেখতে পাবেন। সেখান থেকে `.apk` ফাইলটি ডাউনলোড করে আপনার মোবাইল এবং Android TV-তে ইনস্টল করুন।
